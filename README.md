# Hodavia Portfolio

Portfolio personnel de Hodavia Bangbola, structuré autour de trois univers :

- Me découvrir
- Ambassadrice de marque
- Entrepreneure tech

Le site est construit avec React, Vite et Tailwind CSS, sans TypeScript, et intègre une petite expérience 3D avec Three.js pour renforcer l’univers tech.

## Stack

- React 19
- Vite
- Tailwind CSS 3
- Three.js

## Démarrage rapide

```bash
npm install
npm run dev
```

Le site est ensuite disponible sur l’adresse locale de Vite (généralement http://localhost:5173).

## Production

```bash
npm run build
npm run preview
```

## Objectif visuel

Le portfolio met en place un portail d’entrée cinématographique, puis ouvre sur trois univers visuellement distincts qui restent cohérents entre eux :

- un espace personnel, lumineux et éditorial,
- un univers de marque plus luxe et fashion,
- un univers tech plus digital et futuriste.

Cette logique permet de raconter une même personne à travers trois expressions différentes, sans perdre l’unité de sa vision.
